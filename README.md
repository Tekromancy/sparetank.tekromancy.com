# sparetank.tekromancy.com

Official promotional website, news blog, and hosted privacy documentation for **SpareTank** — the intelligent Android battery longevity manager and emergency reserve guardian.

Hosted live at: **[https://sparetank.tekromancy.com](https://sparetank.tekromancy.com)**

## Tech Stack
- **Framework**: [AstroJS](https://astro.build/) (Static Site Generation)
- **Styling**: Tailwind CSS
- **Deployment**: GitHub Pages / Static Hosting via GitHub Actions

## Features
- **Landing Page**: Feature showcases, battery degradation explanations, Google Play links.
- **Interactive Battery Simulator**: Electrochemical longevity calculator comparing 25%–75% cycling vs deep discharge.
- **Blog**: Engineering articles, release notes, and battery health science.
- **Privacy Policy**: Google Play Developer Policy-compliant privacy policy for SpareTank and SpareTank Pro.

## Local Development

```bash
# Install dependencies
npm install

# Start development server at http://localhost:4321
npm run dev

# Build production static bundle into ./dist
npm run build

# Preview production build locally
npm run preview
```
